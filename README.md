# ISNIB_FER-VR

Official repository accompanying the paper **"A Lightweight FER-VR Closed-Loop Framework for Real-Time Adaptive Teletherapy"**, presented at ISNIB 2026.

## Overview

This work proposes a closed-loop teletherapy framework that integrates a lightweight Facial Emotion Recognition (FER) module with a set of clinically designed Virtual Reality (VR) serious games. During a live teletherapy video call, the FER module analyzes the patient's facial expressions and gaze-based engagement in real time, compiling a post-session emotional report. An automated Decision Engine then matches this report to one of three VR interventions, targeting mindfulness, breathing-based anxiety regulation, and collaborative crowd exposure, closing the loop between AI-driven emotional assessment and immersive therapeutic practice.

## Repository Status

This repository is being released progressively alongside the publication process. Some components, including full hyperparameter configurations and trained model weights, are currently withheld while an ablation study and a dedicated companion paper on the FER model are in progress, and will be released upon their publication.
